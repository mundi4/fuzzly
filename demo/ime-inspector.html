이벤트 시퀀스

compositionstart  → 조합 시작 (selectionStart 캡처)
compositionupdate → event.data = 현재 조합 텍스트
compositionend    → 조합 종료 (data = 최종 확정 텍스트)
input             → 값 변경될 때마다 (조합 중에도 발생)

computed composingRange:
  start = compositionstart 시점의 selectionStart
  end   = start + compositionupdate.data.length
